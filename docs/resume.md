# Dog Breed Classification

**Personal Project | Python, PyTorch, NumPy, scikit-learn**

- Implemented and trained CNN and Vision Transformer classifiers in PyTorch for binary dog breed classification, using training-set normalization, early stopping, and validation-loss-based checkpoint selection.
- Transferred convolutional features from an eight-class source task and compared four layer-freezing strategies, improving held-out test AUROC from 0.7304 to 0.8228 (+0.0924) by freezing all three convolutional layers.

Optional third bullet, when space allows:

- Built an automated experiment pipeline covering freezing, dropout, and weight decay, with training-only augmentation, per-run checkpoints, and validation-based model selection.

The reported AUROC values describe the historical experiments, not a new training run.
